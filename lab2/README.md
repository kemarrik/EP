# Лабораторная работа 2

**Эволюционное программирование и генетические алгоритмы**  
Демидович В. А., Б24-507. Вариант 9.

Задача — назначить аудитории 30 занятиям с фиксированным временем. Учитываются
вместимость, одновременная занятость, недоступные аудитории и закреплённые
назначения. Минимизируется сумма свободных мест и штрафов за нежелательные
аудитории. Это синтетические данные, не реальное расписание МИФИ.

## Установка и запуск

Нужен Python 3.11 или новее. Проверено на Python 3.13.3, NumPy 2.4.2,
Matplotlib 3.10.8. Из папки `EP`:

```bash
cd lab2
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
python plots.py
```

В Windows вместо `source` используется `.venv\Scripts\activate`.
Готовые результаты находятся в `results/`, графики — в `figures/`.
Команды выше перезапишут их. Для сохранения исходных результатов:

```bash
python experiment.py --output results_repeat
python plots.py --results results_repeat --output figures_repeat
```

Серия состоит из 100 запусков: четыре настройки ГА и случайный допустимый поиск,
по 20 seed на метод. Бюджет каждого запуска — ровно 3000 оценённых решений.
После серии отдельно вычисляется точный минимум для проверки качества.
Он не передаётся генетическому алгоритму или случайному поиску.

Пример воспроизведения лучшего результата с seed 1:

```bash
python experiment.py --seed 1 --output results_seed1
```

Команда запускает все пять методов по одному разу. Настройки и seed находятся
в `config.json`. При необходимости можно передать другие файлы:

```bash
python experiment.py --config config.json --data data.json --output results_repeat
```

Синтетические данные уже приложены. Для их восстановления с seed 926:

```bash
python generate_data.py
```

Эта команда перезаписывает `data.json`. После изменения данных или параметров
нужно повторить эксперименты, построить графики и обновить таблицы отчёта.
Визуализация расписания рассчитана на исходные шесть аудиторий и шесть слотов.

## Проверки

```bash
python -m unittest -v
```

Семь проверок покрывают четыре типа ограничений, восстановление допустимости,
точное решение против полного перебора по слотам, фактический расход бюджета,
повторяемость, элитизм, свойства мутаций и обнаружение несовместимых данных.

## Файлы

- `problem.py` — оценка расписания, проверка ограничений, ремонт и отдельный точный эталон.
- `generate_data.py`, `data.json` — генератор и входные данные.
- `ga.py` — ГА и случайный допустимый поиск; готовые оптимизаторы не используются.
- `experiment.py`, `config.json` — запуск серии и её параметры.
- `plots.py` — графики и расписание по сохранённым результатам.
- `test_ga.py` — проверки корректности.
- `REPORT.md` — отчёт в разрешённом формате Markdown.
- `DEFENSE.md` — заметки для подготовки к защите.
- `results/runs.csv` — результат, вектор назначений, seed, время и число ремонтов каждого запуска.
- `results/history.csv` — сходимость и доля допустимых особей.
- `results/summary.csv` — сводная статистика.
- `results/best_schedule.csv` — лучшее расписание в предметной форме.
- `results/examples.json` — два допустимых и два недопустимых решения.
- `results/config_used.json`, `results/data_used.json` — фактически использованные настройки и данные.
- `results/metadata.json` — точный минимум, лучший seed и версии среды.
- `figures/` — пять рисунков, включая схему алгоритма.

Номера аудиторий в генотипе начинаются с нуля: 0 — A1, 5 — A6.
Расписание в CSV и на рисунке использует названия A1–A6.
При одинаковых данных, seed и версиях библиотек воспроизводятся назначения,
значения и история; время работы зависит от машины и нагрузки.

Для просмотра отчёта нужен Markdown-редактор с формулами LaTeX.
При передаче сохраняйте папки `results` и `figures` вместе с отчётом.
