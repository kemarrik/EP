## Запуск первой лабораторной

Из папки `EP`:

```bash
cd lab1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py
python plots.py
```

Нужен Python 3.11 или новее. В Windows вместо `source .venv/bin/activate`
используется `.venv\Scripts\activate`.

Сохранённые результаты и графики уже включены в первую работу.
Повторный запуск перезапишет их. Команды для запуска в другую папку,
воспроизведения отдельного seed и проверки программы приведены
в [README первой лабораторной](lab1/README.md).
