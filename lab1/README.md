# Лабораторная работа 1

**Эволюционное программирование и генетические алгоритмы**  
Демидович В. А., Б24-507. Вариант 9, размерность 8.

Программа минимизирует функцию Диксона — Прайса в области `[-10, 10]^8`.
Генетический алгоритм написан в `ga.py`: турнирный отбор, BLX-α-кроссовер,
гауссовская мутация и элитизм. Готовые библиотеки оптимизации не используются.
NumPy нужен для массивов и случайных чисел, Matplotlib — для графиков.

## Установка

Нужен Python 3.11 или новее. Проверено на Python 3.13.3, NumPy 2.4.2,
Matplotlib 3.10.8 в macOS ARM64. Команды выполнять из папки `lab1`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows вместо `source` используется `.venv\Scripts\activate`.

## Запуск

Полный эксперимент: 20 seed, две настройки ГА и случайный поиск, всего 60 запусков.
Каждый запуск получает ровно 50 000 вычислений функции:

```bash
python experiment.py
python plots.py
```

Результаты уже находятся в `results/`, графики — в `figures/`.
Повторный запуск перезаписывает эти файлы. Чтобы сохранить исходную серию:

```bash
python experiment.py --output results_repeat
python plots.py --results results_repeat --output figures_repeat
```

Воспроизведение seed 2, на котором получен лучший результат первой настройки ГА:

```bash
python experiment.py --seed 2 --output results_seed2
```

Команда выполнит по одному запуску обеих настроек и случайного поиска.
Это пример воспроизведения, а не замена полной серии.

Параметры и список seed задаются в `config.json`. Другой файл передаётся так:

```bash
python experiment.py --config config.json --output results_repeat
```

При фиксированных параметрах, seed и версиях библиотек воспроизводятся векторы,
значения функции и история. Время работы может отличаться. После изменения
параметров и повторного эксперимента численные таблицы в отчёте нужно обновить.

## Проверки

```bash
python -m unittest -v
```

Проверяются значения функции, аналитический минимум, интервал BLX, отключение
скрещивания, границы всех проверенных точек, фактический бюджет, сохранение
лучшего решения и воспроизводимость. Случай неполного последнего поколения
проверяется отдельно вместе с граничными бюджетами.

## Файлы

- `problem.py` — функция, границы и известный минимум для проверки.
- `ga.py` — ГА и базовый случайный поиск.
- `experiment.py` — независимые запуски и статистика.
- `plots.py` — графики по CSV и схема алгоритма.
- `test_ga.py` — проверки корректности.
- `config.json` — настройки эксперимента.
- `REPORT.md` — отчёт с формулами, графиками и выводами.
- `DEFENSE.md` — заметки для подготовки к защите.
- `results/runs.csv` — итог каждой попытки, seed, бюджет, время и координаты.
- `results/history.csv` — лучшее значение после каждого поколения/шага.
- `results/summary.csv` — сводная статистика по методам.
- `results/config_used.json` — копия реально использованной конфигурации.
- `results/environment.json` — среда, в которой проведён эксперимент.
- `figures/` — графики PNG и блок-схема.

`REPORT.md` является отчётом в разрешённом методичкой формате Markdown.
Для просмотра формул и рисунков можно открыть его в Markdown-редакторе с
поддержкой LaTeX. При передаче работы нужно сохранить структуру папок,
потому что картинки подключены относительными ссылками.
